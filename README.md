# Data Science Fundamentals Assessment
## Project: Student Performance Data Analysis

### Objective
Analyze student academic data using Python, statistics, data types, data cleaning, descriptive analysis, correlation, grouping, and visualization.

### Files
- `student_performance.csv` - sample dataset
- `analysis.py` - complete Python analysis
- `requirements.txt` - required Python libraries
- `report.docx` - assessment report

### Concepts Demonstrated
1. Python variables, lists, functions and control flow
2. Pandas DataFrame and CSV handling
3. NumPy numerical operations
4. Data types and missing-value checking
5. Mean, median and standard deviation
6. Group-by analysis
7. Correlation analysis
8. Data visualization using Matplotlib
9. Reproducible and documented analysis

### How to Run
```bash
pip install -r requirements.txt
python analysis.py
```

### Note
The dataset is synthetic and intended for learning/assessment purposes.
